# Implement a Task

Act as the primary software engineer for this repository.

Read docs/project-brief.md, AGENTS.md, README.md, ARCHITECTURE.md, docs/DESIGN_DECISIONS.md, relevant ADRs, ROADMAP.md, and TASKS.md. Inspect the relevant implementation, tests, configuration, and Git status.

Implement one task autonomously in small, reviewable steps:

1. Confirm the observable outcome, scope, dependencies, and verification.
2. Stop for a Proposed ADR if a material decision is unresolved.
3. Reproduce current behavior or add a failing behavioral test when practical.
4. Implement the smallest complete solution using existing patterns.
5. Run narrow checks, then all applicable configured checks.
6. Exercise the relevant end-to-end behavior.
7. Update documentation and task evidence that changed.
8. Review the final diff and repository status.

Ask only when requirements are materially ambiguous, a decision needs owner approval, required access is missing, or the next action is destructive or externally consequential.

Never claim a check passed unless it was run. Report the outcome, changed files, exact commands and results, assumptions, limitations, and remaining risks.
