# Plan a Task

Plan one bounded task in this repository without editing application code.

Read docs/project-brief.md, AGENTS.md, README.md, ARCHITECTURE.md, docs/DESIGN_DECISIONS.md, ROADMAP.md, TASKS.md, and relevant accepted ADRs. Inspect the current implementation, tests, tool configuration, and Git status.

Produce a concise plan containing:

1. The observable outcome and acceptance criteria.
2. Existing files, behavior, and system boundaries affected.
3. Ordered implementation stages, each independently verifiable.
4. Exact tests and behavior-level checks.
5. Risks, assumptions, dependencies, and rollback considerations.
6. Material decisions that require prompts/architect.md.

Prefer existing patterns and verified commands. Identify missing tooling rather than inventing it. Separate must-have work from optional improvements. Stop after the plan unless implementation was explicitly requested.
